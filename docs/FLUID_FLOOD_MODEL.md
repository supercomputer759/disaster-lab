# 유체·침수 프로토타입 모델

`FluidFloodModel`은 SI 단위의 정지 담수 정수압, 부력 및 선형 침수 수위 모델이야. 길이는 m, 밀도 kg/m³, 중력 m/s², 압력 Pa, 합력 N을 사용해. 수온 변화에 따른 밀도 변화는 무시하며 담수 기본 밀도는 1000 kg/m³의 대표값이야. 실제 물 밀도는 온도·압력 조건에 따라 달라질 수 있어.

## 구현 범위

- 게이지 압력은 `p = ρ g h`, 수직 평판의 선형 압력분포 합력은 `F = ρ g b H² / 2`로 계산해. 압력은 깊이에 따라 증가하고, 합력은 바닥에서 `H/3`에 작용해.
- 부력은 아르키메데스 원리 `B = ρ g V_displaced`를 사용해. 입력 체적은 이미 잠긴 체적이어야 해. 부력은 SI 수직 절점하중으로 기존 solver 입력 `loads`에 더할 수 있고, 수직 부재 침수율 도우미는 부재 바닥/상단 좌표와 현재 수위에서 잠긴 높이를 반환해.
- 침수 수위는 설정한 상승률로 목표 수위까지 시간 전진해. 현재 수위를 사용하거나 임의 수면고를 지정해 각 요소의 정수압을 Simpson 적분으로 Euler-Bernoulli 2D 프레임 로컬 등가 절점하중으로 변환하고, `LinearFrameSolver` 분포하중 인자로 변위/단부력을 계산해. 수면을 가로지르는 요소도 수면 위 건조 구간의 가짜 하중을 만들지 않아.
- 구조해석 SI 좌표계는 y축 위쪽이 양수야. 노출면의 `normal_global`은 압력이 작용하는 방향을 지정하므로 반대편 수압을 뺀 압력차를 적용하려면 호출 측에서 순법선/차압을 구성해야 해. 폭은 2D 평면 밖의 부재 폭(m)이야.

## 출처와 한계

[NASA의 유체 압력 설명](https://www.grc.nasa.gov/WWW/K-12/WindTunnel/Activities/fluid_pressure.html)은 깊이가 깊을수록 위쪽 유체 무게로 압력이 증가함을 설명하고, [NASA의 Archimedes 원리](https://www.grc.nasa.gov/WWW/K-12/WindTunnel/Activities/buoy_Archimedes)는 부력이 밀려난 유체 무게와 같음을 설명해. 담수 밀도 기본값 1000 kg/m³는 [NIST 물질 자료](https://physics.nist.gov/cgi-bin/Star/compos.pl?matno=276&mode=text&refer=ap)에 표시된 물 밀도 1.000 g/cm³를 대표값으로 사용했어.

유속, 항력, 파랑, 범람 제트, 수격, 난류, 침수 유동장, 구조물 주변 흐름/차폐, 토사·부유물, 누수 유량, 부재 형상 기반 자동 침수체적은 구현하지 않았어. 부력 API는 구조 강체에 직접 힘을 가하지 않고 N 단위 힘을 반환해. 렌더 픽셀-미터 변환을 정하지 않은 상태에서 이를 Godot `RigidBody2D` 힘에 자동 적용하지 않아. 검증된 해안/홍수 안전 해석이나 실제 유체-구조 연성 모델이라고 주장하지 않아.
