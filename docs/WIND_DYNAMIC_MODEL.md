# 풍하중 및 구조 동적 응답 프로토타입

풍속은 m/s, 기준 높이/절점 좌표/폭은 m, 공기 밀도 kg/m³, 압력 Pa, 절점력 N, 시간 s를 사용해. `WindLoadModel`은 기준 풍속과 power-law 높이 분포, 사용자가 지정하는 방향계수, 표면 법선/폭/압력계수, 단일 반사인 돌풍을 계산한다. 풍향 각도 0°는 구조 좌표계 +X, 90°는 +Y로 바람이 불어가는 방향이야. `outward_normal_global`은 표면의 외향 법선이며 windward 면만 단순화해 하중을 준다.

국소 풍압은 `q(z,t)=0.5 ρ V(z,t)² C_p max(0,-d·n)`으로 둬. `d`는 풍향 단위벡터, `n`은 면 외향 법선, `C_p`는 사용자 입력 압력계수야. 풍속 높이 분포는 `V(z)=V_ref (z/z_ref)^α`이며 α 기본값 0.14는 프로토타입 기본 가정이야. 돌풍은 시작·종료 시 기준 풍속에 반사인 증분을 더해.

요소 풍압은 높이별로 Simpson 적분해 선형 프레임 일관 등가 절점하중으로 변환한다. `FrameDynamicSolver`는 SI 2D 프레임 요소 강성 및 일관 질량 행렬과 Newmark 평균가속도법(β=1/4, γ=1/2)으로 선형 시간 이력 응답을 계산해. 감쇠는 지정 기준 주파수의 질량비례 Rayleigh 감쇠야. 시간별 최대/절점 변위와 풍하중으로 인한 진동을 반환해. 지진 등가관성하중 `-M a_g`와 풍하중은 같은 N 단위 절점하중 사전에서 합산할 수 있어.

## 출처 및 적용 가정

- [NASA Glenn의 속도 효과 자료](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/velocity-effects/)는 동압 `q=½ρV²`와 공기역학적 힘의 속도 제곱 의존성을 설명해.
- [NOAA 풍속시어 설명](https://csl.noaa.gov/projects/lamar/windshearformula.html)과 [NIST 건축물 재해완화 자료](https://nvlpubs.nist.gov/nistpubs/Legacy/BSS/nbsbuildingscience46.pdf)는 power-law 높이 분포가 단순 추정 방식이며 지표 거칠기/지형 조건에 따라 달라짐을 설명해. α 기본값과 압력계수는 이 프로젝트의 시뮬레이션용 조정값이지 지역 설계풍속이나 코드상 하중계수가 아니야.

건물 주변 유동장, 압력계수의 기준별 외피 구역, 흡입·내압, 와류방출, 공력감쇠, 난류 스펙트럼, 실제 지형/돌풍확률 모델은 계산하지 않아. 동적 해석은 소변형 선형 프레임이며 온도/손상/좌굴/접촉과 상호 연성하지 않는다. 시뮬레이션은 구조풍공학 인증 해석이 아니야. 기존 `EarthquakeController`의 화면 픽셀 기반 강체 적용과 혼용하지 않고, 통합 비교 실험은 SI 구조 솔버 경로에서만 선형 중첩을 확인해.
