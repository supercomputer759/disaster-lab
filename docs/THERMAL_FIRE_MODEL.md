# 열·화재 프로토타입 모델

`ThermalFireModel`은 부재별 단일 집중열용량을 사용하는 교육·게임용 모델이야. SI 단위로 온도는 내부 계산 K/기록 °C, 비열 J/(kg·K), 열전도율 W/(m·K), 팽창계수 1/K, 열유속 W를 사용해.

## 열 모델

- 부재 질량은 재료 밀도 × 부재 체적으로 계산하고, 열용량은 질량 × 비열이야.
- 경계 가스 온도는 사용자가 지정한 상수야. 화재 중 대류(설정된 h)와 Stefan–Boltzmann 복사를 계산하고, 화재 종료 후에는 주변 온도에 대한 단순 냉각 경계로 전환해.
- 연결 부재 사이 전도는 접촉 면적, 전도 길이, 두 재료 전도율의 조화평균으로 계산해. 명시적 적분은 열전달계수 선형화에 따라 내부 시간 간격을 제한해.
- 기록은 부재별 현재/최고 온도, 열용량, 비열, 대류·복사·전도 열유속과 시간 이력을 제공해.

## 구조해석 연동

온도에 따른 유지율을 선형 보간해 요소별 영률과 인장/압축/전단/항복 강도에 적용해. 열변형률 `α (T - 20°C)`는 프레임 솔버의 초기변형률 등가 절점하중으로 조립하고, 요소 단부력에서 초기 열하중을 빼서 자유 열팽창을 응력 없는 변위로 계산해. 반환 모델을 `FailureMechanics.progressive_reanalysis()`에 넘기면 열화된 재료 한계를 연쇄 재해석에 사용해.

## 물성 출처와 가정

- 강재: 비열 600 J/(kg·K), 열전도율 45 W/(m·K), 팽창 14×10⁻⁶/K 및 고온 강도/영률 유지율은 [NIST Technical Note 1681](https://nvlpubs.nist.gov/nistpubs/technicalnotes/nist.tn.1681.pdf)의 단순화 물성/Eurocode 3 계수를 참고했어. 해당 표의 500°C 강도계수는 0.78이야.
- 콘크리트: 비열 1000 J/(kg·K), 열전도율 1.3 W/(m·K), 팽창 10×10⁻⁶/K는 [FHWA 콘크리트 열물성 자료](https://www.fhwa.dot.gov/publications/research/infrastructure/pavements/pccp/04127/appa.cfm) 및 NIST 단순 모델을 참고한 대표값이야.
- 목재: 비열 1600 J/(kg·K), 횡방향 열전도율 약 0.13 W/(m·K), 길이방향 팽창 38×10⁻⁶/K는 약 12% 함수율 및 건조 목재를 대표하는 [USDA Wood Handbook](https://www.fpl.fs.usda.gov/documnts/fplgtr/fplgtr113/ch03.pdf) 기반 근사야.
- 소다석회 유리: 비열 720 J/(kg·K), 열전도율 약 1.0 W/(m·K), 팽창 9.1×10⁻⁶/K, 보정 방사율 0.837은 [AGC 기술자료](https://www.agc-yourglass.com/sites/default/files/2023-05/TDS_iplus-energy_0523_EN.pdf)를 참고했어.
- 비철강 재료의 고온 강도/영률 곡선과 일부 방사율은 프로토타입 가정이야. 승인된 설계곡선이 아니며 source 필드/모델 노트에도 이 한계를 표시해.

## 적용 한계

부재 내부 온도 구배, 표준 시간-온도 화재곡선, 접촉 저항, 수분 이동/증발, 콘크리트 박락, 목재 탄화/열분해, 재료 크리프·상변화, 유리 열충격, 기하·재료 비선형성은 모델링하지 않아. 솔버 연동은 선형 정적 구조해석에 온도별 물성 및 균일한 열변형률을 넣는 것이며, 동적 화재 안전 또는 법규 적합성 해석이 아니야. 실제 Godot 강체 엔진의 힘을 열/구조해석 결과라고 표시하지 않아.
